# My Agent Project

Projet Python avec un agent intelligent, conçu pour faciliter vos tâches.

## Installation

1. Assurez-vous d'avoir Python installé (version 3.6 ou supérieure recommandée).
2. Installez les dépendances nécessaires en exécutant la commande suivante :  
   ```
   pip install -r requirements.txt
   ```

## Lancement

Pour démarrer le projet, lancez la commande suivante :  
```
python main.py
```
